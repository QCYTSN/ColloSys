## 具体视觉改变

- 标题、页签、正文和评论组件共享一条最大 850px 的内容列；原生放大截图中发现系统滚动条造成约 5px 偏移，改为按共同工作面计算列宽与起点。代码审查使用铺开的文件 / Diff 双区，适合长路径和代码行。
- 活动改为精细行布局：头像、作者、主题、时间和辅助信息分层；选中只有轻的白色表面，去掉强调竖线和额外加粗。同一成员的色彩取决于成员 ID。
- 保留原 Google Sans 与花生图形；实际字体文件的 wght 为 400–700，opsz 为 17–18，GRAD 为 −50–200。声明匹配实际范围并关闭合成字重。标题 20px / 600、正文 14px、辅助信息 12px、代码 13px；浏览器字体查询确认混排实际使用 Google Sans 与 Microsoft YaHei UI，未整体缩放文字。
- 评论框成为完整输入控件，保留评论语义和行动提示；菜单身份标记、选择箭头、交接上下文、弹窗底部操作统一处理。未增加依赖。
- 活动选择立即提交，只让变化的标题和选中行短暂反馈；阅读面不再整体淡出。菜单、Tabs、引用输出及面板保留短距离进出、可中断行为和 reduced-motion。
