# ColloSys 特化审查：2026-10-24

## 当前路线

以 Codecast 固定版本 `5dfb04f516122fe4f59a61137219b5a4e2e1f9f8` 的完整应用为基础，保留实际桌面框架、工作台、登录、状态仓库与 Convex 数据层，再加入小团队的目录授权、人工编辑采集、可恢复检查点及协作查看。原 Workers/D1 与 `packages/web` 是历史实现，不是当前产品基础。原始镜像保持不变；改动由 `integrations/codecast` 重现到 `.local/codecast-app/source`。

## 已复现的问题及修复方向

旧版本实测证据：`.local/codecast-app/backend-audit-1792832626965/result.json`。这是修复前测试结果，不是通过验收的报告。

| 发现 | 修复 |
| --- | --- |
| 新工作区直接渲染查询结果，与 Codecast 原缓存/撤权边界脱节 | 注册 `colloEvents` / `colloWorkspaces`，查询仅向原 store 供数，使用原集合读取；账号 epoch 阻止旧请求落回；项目拒绝与团队撤权清理缓存 |
| 多条传输片段被展示成多个检查点；选中对象仅存在于已加载的一页 | 每个工作区/检查点一条活动；索引查询完整片段，核验缺失/重复/矛盾；独立事件深链及详情，不依赖翻到该页 |
| 视图本地选择绕开原生页签导航 | 使用 `event` 地址参数及原 pane-aware router；复用原 DetailSplitLayout、Rail、SegmentedToggle、DiffView |
| 缓存后恢复订阅时，简单使用旧尾游标可能跳过超过一页的新事件 | 新 head 必须补读到上次确认 head，再沿旧 tail 加载更早记录；片段迟到时重读已加载范围 |
| 同 checkpoint 重复 part 换 ID、矛盾 parts 均被服务端接受 | 索引与事务元数据校验；新事件统计分片与文件数；旧数据标为未验证，不虚报完整 |
| 退出登录后，旧 JWT 仍能读取/创建原生项目 | 在原公开 query/mutation/action 边界检查活动会话；原生直接引用 raw builder 的模块同样适配；保留内部函数与匿名入口的适用行为 |
| 九人团队两人并发加入，最终出现十一人 | 在事务数据库写入边界统一检查 `team_memberships` 容量，涵盖不同原生加入入口 |
| Codex 会话转到另一项目后消息仍归于原目录 | 每轮读取 `turn_context.cwd`；不依据会话最初目录继续归属后续轮次 |
| 畸形 JSON 结构中断日志采集 | 跳过无效结构并继续后续有效消息 |
| 两个重启进程可并发删除旧 PID 锁而双写 | 以独立 SQLite 系统锁串行化恢复；保留 PID 记录；真实进程被终止后检查锁释放 |
| 创建状态路径可能先穿过 junction，再报告非法路径 | 创建前检查现存祖先；测试确认不会在链接目标中留下目录 |
| Codex 预览消息数读取了错误字段 | 读取实际的 `userMessages + assistantMessages` |
| 日志路径在等待预览时可编辑，旧结果可能被用于确认另一来源 | 预览绑定请求路径；连接只使用匹配的已预览路径；请求期间锁定来源和历史共享选项，真实延迟回归验证 |
| 已排除的二进制文件被描述成已保存，旧历史也无条件宣称可恢复 | 排除状态优先说明当前内容未捕获；历史恢复取决于本地保留状态；加载中的新检查点不冒充旧版未验证记录 |

## 原有正确路径与证据边界

故障注入确认：服务端落盘后连接断开、收到无效 ACK 时，事件仍留在 outbox，合法确认后才移除；服务端只有一条事件。检查点第二片 SQLite 写入失败时整组回滚，重试保留 Git 引用；恢复前备份因额度不足失败时不修改工作目录。这些是补充验证，不冒充本轮修复。

`npm run typecheck` 原来只检查根项目，不包含完整 Codecast 集成。新增 `npm run typecheck:integration` 针对实际生成 fork 的自有文件，用真实上游类型检查；它不等同于运行上游全部应用、全部测试或正式发布验证。

## 仍不能称为完成的范围

- 原生任务、评论可继续使用；只读 Codex 日志尚未变成原生可继续执行的 Agent 会话，也未实现 Delta 式共享执行/模型上下文交接。
- 连接程序已有保留策略、额度和加密备份能力；其旧版操作界面不能算作已完整迁入当前 Codecast 工作台。需要独立验收当前桌面中的相应管理流程。
- 全量保留上游源码不表示每项云端/外部能力在本地可用。当前禁止的外部请求仍被本地边界阻断；需继续按实际工作流程整理可见入口。
- 正式 Windows 安装/升级分发、异地十人、生产认证、远端备份运维、公网部署不由本地测试证明。本轮没有购买或部署服务。

本轮实际运行命令、结果与证据目录统一记录在 `PLAN.md` 第九轮；只有测试执行完后才填通过结果。
