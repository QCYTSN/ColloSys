# 本地验收步骤

这份检查用于确认真实文件、数据库和连接程序都参与了流程。演示身份是 Alice / Bob，演示文件明确标记为测试内容；页面不生成虚构活动。

## 准备

在仓库运行 `npm run dev`，打开 `http://127.0.0.1:5173`。

- 普通浏览器窗口选择 Alice。
- 无痕窗口选择 Bob。
- Alice 目录：`.local/demo/alice/project`。
- Bob 目录：`.local/demo/bob/project`。

两个页面都应显示实时连接。连接程序状态应对应各自目录。

## 人工编辑与查看

1. 在 Alice 目录中新建 `manual-acceptance.txt`，写入 `TEST FIXTURE: first version` 并保存。
2. Bob 页面应出现 Alice 的新增活动，并能查看文件内容差异。
3. 修改该文件并保存。Bob 应看到修改差异。
4. 检查 Bob 的磁盘目录：不会因为看到 Alice 的活动就出现该文件。
5. 在 Alice 页面保存一个手动检查点，记住其时间或编号。

## 暂停发送与补齐

1. Alice 页面点击“暂停发送”。
2. 再次修改并保存文件，等待本地待发送计数增加。
3. Bob 不应收到这些尚未发送的变化。
4. 点击“恢复发送”。待发送记录应清空，Bob 应看到补齐后的变化。

这个按钮验证本地发送队列，不能单独作为系统断网验收。`npm run test:e2e` 另外会真正停止并重启独立测试后端，同时让连接程序继续捕获；还会重启连接程序检查队列是否持久化。

## 预览与恢复

1. 把 Alice 的测试文件内容改坏并保存。
2. 在“我的检查点”选择改坏之前的检查点，点击“预览恢复”。
3. 检查预览目录和变化列表。未确认时，Alice 当前目录不应被修改。
4. 勾选确认后恢复。Alice 文件应回到选定内容，历史中应保留恢复前备份。
5. 再次检查 Bob 目录，确认没有被恢复操作修改。
6. 额外检查：打开预览后，再用编辑器修改文件。此时确认旧预览应被拒绝，需要重新预览。

## 权限与文件边界

- 使用“非项目成员”身份登录，应该看不到项目内容。
- 在 Alice 目录创建仅含测试值的 `.env`。其路径和内容都不应进入共享活动；不要为测试写入真实凭证。
- “连接设置”中把 Alice 的连接地址改为 Bob 的本地端口，应该拒绝连接。
- 排除规则、链接和文件大小限制可以在连接设置里查看。超限文件没有被保存，不能据此承诺恢复。

## Agent 会话

手动文件流程不需要启动 Agent。接入真实会话时，使用属于当前授权项目的 Codex rollout 文件，在“连接设置”中检查并确认共享。默认不导入已有历史。

自动化测试使用明确标记的日志夹具；实际当前 Codex 日志只做过读取和解析验证，没有被隐式上传。已经支持在用户明确授权的日志目录中查找 cwd 匹配的会话，发现结果不会自动上传，选择来源后仍需确认共享。其他 Agent 适配和系统内控制 Agent 尚未实现。

## 历史与工作台

- 活动、会话和协作记录可继续加载更早内容；刷新后旧任务的状态和版本仍应更新。
- 打开检查点的不同文件，确认实际代码差异可读，分批到达的文件清单会补齐。
- 打开长会话，加载更早消息时当前阅读位置应保持；离开底部时新消息不强制拉动页面。
- 复制活动链接并刷新，仍能定位该详情。窄屏返回应恢复列表，不反复自动打开详情。
- 故意中断详情请求后的“重试”应恢复该详情。自动浏览器回归使用受控失败验证此项。

## 自动验收与证据

- `npm test`：文件边界、真实快照、恢复、队列和解析等核心测试。
- `npm run test:e2e`：独立本地后端与两个目录的集成流程，结果写入 `.local/acceptance/<run>/result.json`。
- `npm run test:browser`：先启动本地环境；使用 Chrome 进行真实双身份界面验收，截图在 `.local/verification`。
- `npm run test:reliability`：隔离的真实 Worker/R2/DO 中验证上传代次、撤权与重新认证；结果在 `.local/reliability`。
- `npm run test:extended`：真实密码账号、团队权限、备份/重建及持久化；结果在 `.local/extended`。
- `npm run typecheck` 和 `npm run build`：类型检查与可交付前端构建。

实际执行次数与结果以 [PLAN.md](../PLAN.md) 为准。上述测试不替代异地十人使用、正式身份认证、安装分发、资源配额与公网部署验收。
