# 安装与使用

**旧版说明：**下列安装包属于此前的 Workers/自制界面版本。当前完整 Codecast 版本请在仓库使用 `npm start`，参阅 [README](../README.md)；新版安装包尚未迁移。不要用旧安装包验证这次的前端。

## Windows 安装包

构建机器需要 Node.js 24.15.0、Git 和已安装依赖。执行 `npm run build`、`npm run package:windows`，得到 `dist/ColloSys-Windows-<时间>.zip` 及 SHA-256 校验文件。

安装包包含 Node、应用和依赖；使用机器仍需安装 Git for Windows。无需 Cloudflare 账号、npm 下载或模型 API。

1. 解压 ZIP，双击 `Install.cmd`。默认安装到 `%LOCALAPPDATA%\Programs\ColloSys`；已有安装不会被覆盖。
2. 使用桌面 ColloSys 快捷方式打开。启动器在后台启动本机服务，浏览器携带启动配对信息。再次打开快捷方式可回到已有服务。
3. 注册个人账号，或使用已有用户名和密码登录。此启动方式禁用 Alice/Bob 演示登录。
4. 在“团队与账号”创建团队、创建项目、生成加入码。加入码仅显示给创建者一次，24 小时有效、单次使用，可撤销；请自行交给组员。应用不发送邮件。
5. 在“接入项目目录”浏览或填入自己的目录，勾选授权。它创建独立连接程序和状态，不移动项目文件。
6. 重启应用后，到同一窗口选择已有工作区“启动并连接”。这样会更新登录凭证，保留原检查点和离线队列。
7. 可在项目接入窗口关闭本机服务。安装目录可手动移除；项目和 `%LOCALAPPDATA%\ColloSys\data` 不会被卸载操作删除。

启动错误日志：`%LOCALAPPDATA%\ColloSys\data\launcher-error.log`。不要公开状态文件、口令或登录配置。

这是未签名的 ZIP + PowerShell 用户目录安装包，尚未制作签名 MSI、自动更新器或 macOS/Linux 安装包。Windows 文件夹选择器已有实现；自动验收使用填写绝对路径的同一授权流程。

验证边界：安装与包内 Node 启动可独立验收；桌面 VBS/PowerShell 入口此前被自动审批以 `blocked by policy` 拒绝执行，未绕过重试，因此上述快捷方式流程尚未完成自动实测。最新包及实测记录以 `PLAN.md` 最后一节为准。

## 从源码启动真实账号环境

```powershell
npm ci
npm run build
npm start
```

首次运行生成本机账号 pepper，保存在数据目录 `local-auth.env`。后端绑定 `127.0.0.1:8787`，界面 `127.0.0.1:5173`，管理程序 `127.0.0.1:8790`。项目连接程序使用空闲本地端口。请保留 `local-auth.env`，它丢失后已有密码无法验证。

`npm run dev` 是另一个模式：初始化 Alice/Bob 演示目录和开发登录，数据在仓库 `.local`。两种模式不能同时占用同一组端口。

## 任务与交接

- 项目编辑成员可以创建任务、指定负责人、修改状态和发表评论。查看者只能阅读。
- 同一任务有版本号；过期编辑不会覆盖另一个成员刚保存的版本。
- 交接包含进展、下一步、任务及真实活动引用。只有指定接收成员能接受或拒绝。
- 这是上下文交接；系统不启动远程 Agent、不传递正在执行的工具进程，也不替队友应用代码。

## Codex 来源

在连接设置中填写明确授权的日志目录，搜索只返回 cwd 匹配项目的会话。搜索不会上传消息；选中日志后仍须单独确认共享。已有消息默认不导入。采集一个选定文件，不自动扩展授权到其他日志；日志轮换后重新选择。

## 保留、备份与恢复

- 默认保留最近 200 个且不超过 30 天的检查点，预算 2 GiB，可在“我的检查点”修改。
- 最新两个、手动固定、待发送及有效预览引用的检查点受保护。达到预算会停止新捕获，不丢弃未发送记录。预算是应用层的写入准入检查，不是操作系统硬配额。
- 普通恢复预览有效 10 分钟，使用后失效，下一次维护删除其预览文件。恢复前备份仍是独立检查点。
- 备份前在本地用 AES-256-GCM 加密，口令通过 scrypt 派生密钥，只在操作期间使用。选择至少 16 字符口令并另行保管；系统无法找回口令。
- 每个压缩备份最多 24 MiB，每位成员每项目的对象存储预算 512 MiB，未完成上传也占用预算。超限明确失败，不把部分文件冒充完整备份。
- “本机对象存储”仍在这台电脑，无法抵御整机丢失。只有部署后端、配置真实 R2 并收到完成回执，才显示远端备份。
- 解密重建写入新的独立预览目录，验证文件哈希，不改变当前项目。预览保留 24 小时；请及时复制需要的文件。
- 备份覆盖允许捕获的普通文件。凭证、忽略文件、依赖、超过单文件限制的内容、ACL 和符号链接不在范围。

## 以后连接在线后端

部署通过后，设置 `COLLOSYS_BACKEND=https://你的后端域名` 再启动应用。本机启动器继续提供界面和配对管理，将请求代理到该后端，不在本机启动第二套协作后端。

本轮没有部署公网。实际跨网络、TLS、睡眠唤醒和多机使用待上线验收。见 [部署说明](DEPLOYMENT.md)。
