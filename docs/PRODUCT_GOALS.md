# ColloSys 当前产品目标（供调整）

目标：面向最多 10 人的小团队，让成员保留各自的编辑器、Agent 和独立项目目录，共享真实开发活动、查看差异和会话，并安全恢复自己的代码。

## 当前目标清单

1. 研究 Delta 与 Codecast 的实际源码，记录实现链路、复用来源与缺口；未公开部分明确标为未知。
2. 通过本地连接程序接入用户明确授权的项目目录，不要求统一编辑器或 Agent。
3. 手动保存文件也能触发检测、差异和真实检查点，不依赖 Agent 启动。
4. 其他成员可以查看谁、在哪个工作区、什么时候发生了哪些变化；共享活动不自动修改队友目录。
5. 至少接入一种真实 Agent 会话来源。会话与检查点关联须说明证据边界，不能把时间相邻冒充修改因果。
6. 保存可恢复的文件内容；恢复经过独立预览、当前状态备份、用户确认和变更复查。
7. 后端持久化事件、检查成员权限、推送更新，支持离线积压、补发和重复事件去重。
8. 第一版前端、本地程序与后端完整本地运行。当前不购买、部署或暴露公网服务。
9. 用两个身份、两个真实目录、两个浏览器会话完成编辑、共享查看、断线补发和恢复验收。
10. 交付可运行源码、启动方式、复用清单、实际测试记录，以及未实现与上线后待验证事项。

## 本轮已确认的范围

用户已选择先完成任务、评论和会话交接；本轮同时授权账号团队管理、Windows 安装接入、保留策略与加密备份。没有授权购买、部署公网、创建隧道或发送真实邀请。

## 后续可以调整的产品选择

- 协作深度：活动与会话共享；任务分工、评论和交接；或进一步接收、应用与合并队友修改。
- Agent 角色：采集外部工具的会话；或在 ColloSys 内直接启动、控制和接管 Agent。
- 代码共享：仅活动与差异；远端完整检查点备份；或共享分支、评审和合并。
- 会话共享范围：当前仅用户和公开助手消息；是否加入选定工具调用及结果、评论，以及更细的可见范围，需要另定规则。内部推理不采集。
- 第一版用户规模与场景：最多 10 人是设计目标；同机测试不能替代真实异地团队验证。
- 前端、后端和桌面形态：当前 React、独立连接进程、Cloudflare 是实现选择。暂用 Codecast 适合的 UI 部分，最终设计未冻结。

本轮交接是可确认的上下文交接，包含实际活动引用、进度与下一步；不表示远程启动或接管 Agent。队友文件应用与自动合并仍不在本轮范围。

## 当前暂缓

收费订阅、邮件投递、远程 Shell、系统内 Agent 控制、自动合并、多人同时改写同一目录、公开资源购买与公网部署。

最终产品可以朝“安装、登录、邀请组员即可使用”推进；本轮已实现本地安装、密码账号、加入码、项目接入和协作闭环；实际异地使用仍需部署及公网验收。

这些是当前迭代取舍，不表示最终产品永久排除这些能力。
