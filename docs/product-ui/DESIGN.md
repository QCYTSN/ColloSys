# ColloSys：统一视觉语言与精密参数实施规格 v1

本轮只采用这一份新增设计指令。

保留既有业务事实、认证、权限、恢复保护与已正确实现的交互；
撤销旧任务中与本轮冲突的花生角色、Fold 陶土物体、各页自行配色、
局部随意定尺寸等要求。

本文件中的尺寸、颜色和动效参数，是为 ColloSys 制定的实施规格，
不是声称从 Claude 私有前端测得的官方数值。

先按此实现，再做有证据、有限度的整体校准。
不要重新发明另一套风格，不要只在旧界面上叠一层“美化 CSS”。

## 0. 工作基线、范围与交付含义

项目：QCYTSN/ColloSys。

已审查基线：
codex/product-ui
f4a1e815ef2fc63612e7d22f8dcd61576eab71cd

及实际加载资源。基线不是回退命令。

本轮不是继续给一个页面补阴影，而是统一正式应用的美术与排版系统。

1. 静止画面有明确的轻重、完整的比例和自己的辨识度，

   不是吉祥物，不再是整张 Fold 图片漂浮。

   目录/备份与正常桌面入口不退化。

5. UI 动效有实际的按压、开合与状态连续性，
   不靠文字缩放、整屏淡出或延迟响应制造效果。

不要为了更换左侧画面擅自重做全站品牌资产。

去覆盖本任务的明确设计。

不卸载全局插件，不修改无关安全设置。
正常代码、浏览器、测试工具可以继续使用。

允许修改所有自有展示层的布局、token、组件造型及相关状态接缝。
不更换后端、账号体系、store、Diff 引擎或代码框架。

交付必须进入正常 npm start，覆盖：

目录历史与存储、设置、认证与加载。

## 1. 将“借鉴 Claude”转换成具体设计操作

可核实的设计依据：

Anthropic 早期品牌设计采用 Styrene 无衬线与 Tiempos 衬线搭配。
其品牌团队描述了书籍感文字、像观察随记的插画、
有人味但不过度抛光的表达。

这些不是当前 Claude 每一个账号页面的像素规格。

不要将公开品牌 artifact 模板里的字体列表，
冒充当前 Claude App 的字体实测。

本轮采用的方法与明确落点：

| 参考方法 | ColloSys 的具体决定 | 禁止的误读 |
|---|---|---|
| 表达性文字与功能性文字分工 | 仅登录艺术标题使用 Newsreader；菜单、按钮、列表、会话继续 Google Sans | 全站衬线、全站超大标题、复制 Claude 商业字体 |
| 柔和背景与明确深色文字相配 | 轻微绿灰外壳、白色工作面、深墨绿主操作 | 全屏奶油色、全部元素都淡、复制陶土橙按钮 |
| 艺术插画与精确 UI 共存 | 登录/首次引导使用少量自然色块；工作区保持精确对齐和规则控件 | 每张卡片都插画化、让列表故意不齐 |
| 用留白组织内容 | 共用阅读轴，区分组内与组间距离 | 把字缩小后放进无理由的大空白 |
| 品牌、内容、工具有不同职责 | 艺术颜色与功能强调色分开 | 从插画随机抽五种颜色分配给五类按钮 |
| 动态辅助理解变化 | 按本任务的按压、菜单、面板、状态动效表执行 | 每次刷新都做入场动画，或编造 Claude 的精确动画时长 |

Photo Abstract Editorial 只提供一般构图启发：

从空间关系提炼平面构成，而不是放一件不明抽象物体做装饰。

不安装该 skill，不复制其提示词、实例构图、摄影或分发素材。
仓库声明商业用途需授权。
本轮风景是独立原创，不伪称由用户照片提取。

参考职责：

- Claude/Anthropic：表达性文字、艺术与功能秩序的分工。
- Photo Abstract Editorial：平面色块、疏密、遮挡、负空间。
- OpenDesign：表面分层、控件组合、浮层微观精度。
- Codecast：可靠行为和复杂内容，不再决定整套外形。

不要每个参考各拿一半，拼成四种风格。

应用规则：

1. 常驻工作面不用 backdrop-filter。
   不让正文通过半透明父容器一起变淡。

2. 默认不加纸纹、颗粒、噪声、全屏渐变、发光和大范围磨砂。

3. 选中状态主要用轻底色＋清楚文字，必要时有勾选。
   不同时堆深边框、竖色条、重阴影、粗字五种信号。

4. 禁用与普通辅助文字分开。
   不能让所有次要内容都像不能点击或已经失效。

5. 普通文字实际组合目标至少4.5:1；
   焦点和必要状态边界目标至少3:1。
   检查真实背景与透明合成，而不只测主文字对白色。

6. Diff 增删、语法高亮、第三方 Agent 标记保留自身语义。
   不强行全部改成绿色。

7. 启动 HTML、React、portal 浮层与原生窗口背景同源。
   不允许首帧闪旧紫色/旧主题。

## 4. 字体：角色、字号、字重、字距与光学尺寸

### 4.1 字体选择

UI 拉丁文字：
保留本地 Google Sans。

UI 简体中文：
本地 Noto Sans SC，
后备 Microsoft YaHei UI / sans-serif。

如果已有同等可靠的中文资产可以复用，
明确其版本与实际效果，不静默变成不确定系统回退。

英文品牌/艺术标题：
Newsreader Roman。

Newsreader 只用于：
登录艺术标题、少量 onboarding 或品牌空状态。

不得用于：
按钮、任务标题、会话正文、导航、表格和设置。

中文品牌标题：
Noto Sans SC 500，保持相同内容角色。
不因为 Newsreader 缺中文字形，就留下偶然的 fallback 风格。

代码：
保留现有 Cascadia Code/Consolas 等等宽链。
验证实际安装及中文注释，不在本轮重换 Diff 引擎。

字体从官方可授权来源本地托管，保留许可。
不下载 Claude 商业字体，不使用运行时字体 CDN。

需要转换 WOFF2 或 unicode-range 分片时，
保证字形覆盖，不只保留测试页面出现过的汉字。

品牌字体只在需要时加载，不拖慢日常工作区。

### 4.2 Google Sans 轴值

先检查实际 GoogleSans.ttf 的 name/fvar/字形覆盖。

官方现行 Google Sans 源码描述：
- wght：400–700
- opsz：17–18
- GRAD：-50–200

当前文件仍须实际检查。
不能假定它含有 Google Sans Flex 的所有轴。

确认支持之后：

- 12–17px UI/正文角色：opsz=17，GRAD=0。
- 18px及以上标题/Logo角色：opsz=18，GRAD=0。
- 字重由 font-weight 按角色控制。
- 不在全局 font-variation-settings 锁死 wght。
- Newsreader 使用自己的光学尺寸逻辑，
  不继承 Google Sans 的 opsz=17。

文件缺少轴时不假装应用。
不得通过 synthetic bold 伪造不存在的字重。

不全局靠加描边、text-shadow、强制 font-smoothing
制造“更粗更锐”的假象。

Windows 实际光栅化必须实际看，
一个 CSS 开关不是跨平台答案。

所有尺寸为 CSS px。

## 5. 空间与整体比例：本轮必须真正改主界面

### 5.1 间距尺度

使用：
2、4、8、12、16、20、24、32、40、48、64。

- 2/4：文字与辅助标记、光学校正。
- 8：图标与文字、同类控件。
- 12/16：组件内部、连续行。
- 24：基础页面内边距、内容组之间。
- 32/40：主要区块、宽屏疏密变化。
- 48/64：仅品牌/认证等低密度画面。

不能用48/64把普通列表撑空。

### 5.2 圆角与线宽

圆角：
- 标签4。
- 控件8。
- 菜单12。
- 内容面12。
- Dialog16。
- 颜色圆点/头像可50%。

不要各页继续新增6/7/9/10/11px规格。
必要例外必须说明角色和实际原因。

默认边线1px。
Focus ring2px。
不为了“扎实”把所有边线加粗。

### 5.3 阴影

常驻内容面：默认无阴影。

Secondary按钮：
0 1px 1px rgb(22 34 27 / .06)

菜单：
0 1px 2px rgb(22 34 27 / .06),
0 8px 24px rgb(22 34 27 / .10)

Dialog：
0 8px 24px rgb(22 34 27 / .10),
0 24px 64px rgb(22 34 27 / .16)

遮罩：
浅色环境黑色20%；
深色环境可以黑色36%。

不模糊整个应用背景。
面板边线仍要清楚，不能只靠一团阴影定位。

### 5.4 桌面外壳

默认侧栏232px。
允许用户拖动208–280px，并保留用户选择。

主顶栏48px。
多工作标签栏32px。
已有多工作切换功能不能被删除。

主内容面外侧留12px，
只有一层主要content surface，圆角12。

侧栏底色=surface-app。
工作面=surface-content。

导航行：
36px高，14/20文字，左右12px，
图标18px，图标与文字间8px。

分组间16px，不给每组都塞10px大写标题。

对象头：
默认56px高，20/28标题。

相关页签与工具条：
尽可能合为40px的一条内容带；
小宽度确实需要时再合理换行。

不允许同一个项目名在顶部、眉题、页面h1重复出现三遍。

默认1440×900时，
主工作内容应在顶部约200 CSS px以内开始。

这是空间预算，不是审美证书。
不能缩字、删必要状态或裁掉工具栏来达标。

### 5.5 项目/活动列表

页面padding24；>1600px宽屏可32。
页面头下距24，筛选到列表12。

单行记录min-height44。

双行记录min-height64：
14/20主题＋2px间隔＋12/18辅助信息，
上下12px。

长标题允许增高，不锁死高度裁字。
提供完整查看路径。

内容主题先被看见；
成员、来源、时间提供上下文。

不把 sessionId 和实现分类当作主要内容。
优先使用已有标题或真实请求片段，
不新增AI摘要调用。

项目概览列默认320px，
主索引min520px，两栏间24px。

实际容器不足900px时，
切为单栏＋按需详情入口，
不把两栏挤成细条。

每条记录不同时加卡片框、底线、浮影和选中色条。
主要依靠对齐、间距与低对比分隔。

### 5.6 会话与代码

标题、正文、评论框、加载更多和状态提示，
共用最大宽720px的内容列。

不能正文居中，标题贴边，输入框又在另一条轴线上。

评论框padding16、radius12；
与正文保留16–20px间距。

需要解释与代码并排时：

- 阅读区min420px。
- 代码区min600px。
- 分割条与间隔计入实际可用宽度。

容器不够宽时转为可切换模式，
保留当前文件、行号、阅读锚点。

Diff按剩余高度布局。
不再嵌在固定58vh盒子里叠多层滚动。

文件树可独立滚动，代码可合法横滚。
截断、错误、完整性和恢复限制仍然可见。

| 页签 | 高36、左右12、字13/18-500 | 当前项底线或轻面二选一 |
| Active菜单 | 宽224、内边4、radius12 | 行min34，左右10，上下8与18行高协调 |
| Display面板 | 宽320、padding16、radius12 | 标签列80，值列弹性，行距12 |
| 菜单项 | 字13/18-400，当前项500；图标16；tick14 | 选中、Hover、Focus不同 |
| Dialog | 常规560，复杂720；外边24；padding24；radius16 | 表单分组距16，操作区距24 |

按盒模型实际计算。
不能声明34px高，又用padding和line-height把内容挤出去。

宽度使用max-width和真实空间约束，
不强行撑开小窗口。

Active/Display 在 f4a1e8 已经接入 Radix 和自有组件。
保留这一成果，不回到普通button＋条件div显隐。

Display继续显示当前配置，候选项按需打开。
保留分组轴、排序、方向、List/Board、保存视图和分享能力。

原生select与自定义select按同角色校准。
更换实现必须回归键盘/焦点，不为一个动画全站替换。

## 7. 登录艺术定案：平面色块水岸

不要再寻找另一件不明抽象物体。

### 7.1 整页

>1100px：
左54% / 右46%。

960–1100px：
左48% / 右52%。

<=820px：
左侧可收成品牌条或隐藏艺术，表单继续可用。

左面四周16px，radius16，
背景 #EDF0E8。

右表单最大宽368px，
左右最少32px。

表单主体竖向居中，
底部辅助说明与主体间24px。

注册或错误使内容变长时允许合理滚动，
不能硬居中裁掉表单头尾。

左上Logo区24px边距，Logo约24px高。
不再放第二个超大Logo。

右标题：
28/36 Google Sans 600。

左艺术标题：
36/42 Newsreader 450，最多两行。

建议文案：
Separate paths.
Shared direction.

可以为准确表达产品做小幅文案修订，
但不增加泛泛的AI宣传段落或四层标语。

### 7.2 内容

采用原创简化水岸：

远处低山、平静水面、一段近岸、少量光线。

承担安静、开阔、有秩序的氛围。
不需要解释API、Agent网络或后端结构。

风格是平面、低细节、自然比例的色块构成。

明确排除：

- 3D陶瓷、金属、橡胶渲染。
- 玻璃球、漂浮石头、莫比乌斯环。
- 吉祥物、眼睛、信封和机器人。
- 伪产品卡片与随机连接线。
- 三个随意矩形贴上“抽象美景”标签。
- 用噪声、纸纹、模糊掩盖造型问题。

艺术色板：

| 角色 | 颜色 |
|---|---|
| 留白/场地 | #EDF0E8 |
| 远处浅层 | #D6E0D7 |
| 主水面蓝灰 | #7B969B |
| 岸线暖石色 | #BC9670 |
| 深结构 | #344D48 |
| 极少量光色 | #C39448 |

光色最多占可见色块面积约3%。
这些艺术颜色不全部映射成UI强调色。

### 7.3 构图约束

使用 viewBox 0 0 800 600 的可伸缩画面。

初始结构：

- 地平关系在y=250–285附近，不居中机械对半。
- 远山横跨x=110–650，峰脊低。
- 远山主要高度在y=180–275，不画等距三角形。
- 水面延展到x约690，主要位于y=280–365。
- 近岸从左下进入，与水面形成遮挡。
- 深色用于一小段近岸或岸线，不给所有形状统一描黑边。

3–5个主要色块，
最多再加一组细线/短光带。

整体宽约画面65%–78%，
高约32%–45%。

保留一半以上安静背景，
但主体不能缩得像一个小图标。

形状有轻微不对称、不同尺度和停顿。
不要等大、等距、完美镜像，也不要随机blob。

这些坐标是构图起点，不是让你画死板多边形。
必须在完整左右登录布局中校准轮廓与负空间。

允许调整整组位置、比例和曲率，
不允许又换成另一个题材。

### 7.4 分层资产

优先使用原创分层SVG：

背景、远山、水面、近岸、光带分别独立。

可以用实际可用的视觉工具辅助构图，
最终必须有适合局部动画的本地原创资产。

不能再交另一张整图webp，
然后通过外层transform声称有了场景交互。

不复制参考仓库实例或受限提示词。
不把第三方图片改色后宣称原创。

### 7.5 动作

静止画面先成立，再加入以下动作：

- 远山和主岸线稳定，整幅画不倾斜、不呼吸缩放。
- 水面中一条很窄的倒影层水平位移约±9 SVG单位，
  8秒周期、ease-in-out。
- 聚焦输入时，一段光带在220ms内平移6 SVG单位，
  或适度提高透明度。
- 密码聚焦不读取内容/长度，不表演“看密码”。
- 真实提交或OAuth等待时，
  光带在mask内以1.8秒周期走过60–80 SVG单位。
- 成功时一次200ms的光带落定或轻微增亮，
  导航不等待动画。
- 错误由表单清楚表达，画面不整片变红。
- reduced-motion、后台、窗口最小化、离屏时，
  停止持续运动。

正常默认状态连续观察约2秒，
应能辨认水纹局部有变化，
不能八秒只整张图漂3px。

也不能为通过像素差测试让画面闪烁。

这是“光与水在变化”，
不是无脸物体假装表情。

艺术组件只接受安全展示状态，
不接邮箱、密码、用户对象或业务数据。

## 8. 轻动效：对象、属性、时长与中断规则

曲线：

出现/恢复：
cubic-bezier(.2,.8,.2,1)

退出：
cubic-bezier(.4,0,1,1)

小状态交叉：
cubic-bezier(.4,0,.2,1)

| 动作 | 属性/幅度 | 时长 | 保持不变 |
|---|---|---:|---|
| Hover | 背景/边框/文字色 | 100ms | 不位移正文、不抢焦点 |
| 按下 | 完整可见控件面向下0.7px | 70ms | 外层锚点不缩放 |
| 松开 | 回原位并恢复短阴影 | 130ms | 点击逻辑立即执行 |
| 菜单进入 | opacity0→1，沿锚点方向4→0px | 160ms | 出现即能操作 |
| 菜单退出 | opacity1→0，位移0→2px | 100ms | 退出节点不拦截新操作 |
| Tab指示 | 指示器位置/宽度 | 160ms | 正文不整块闪白 |
| 详情进退 | 局部opacity＋最多6px位移 | 180/140ms | 外壳、列表位置、焦点 |
| 面板开合 | 共同layout进程 | 200ms | 尺寸约束与阅读锚点 |
| 分栏拖动 | 即时几何 | 0ms | 分割线跟随指针 |
| Dialog | opacity＋4px位移 | 180/140ms | 焦点陷阱、归还、Escape |
| 复制/保存反馈 | 图标/短文字交叉 | 120ms | 容器宽度稳定 |

### 修正当前 ListTrigger 的问题

当前实现主要缩放内部文字/图标，
背景、边框仍停在原来的外层。

本轮需要让完整可见表面表达按压，
不是字缩一下、外框不动。

可以采用：

稳定button盒
＋内部完整surface
＋内容

内部surface承载背景、边框与内容。
外层负责稳定锚定、命中和焦点环。

或者使用完整表面的阴影/位移反馈，
不必缩放文字。

不得嵌套button，
不得吞掉Radix/asChild/ref事件链。

### 状态规则

Pressed、Open、Focus-visible、Selected分别设计。

展开时：
触发器保留轻底色，箭头对应转180°。

选项勾选：
只表示当前值，不表示鼠标经过。

键盘Focus：
2px清楚焦点环，不能被删除，
也不能拿它代替唯一的Open反馈。

同一属性只由一个动画拥有者控制。
不要CSS、transition、WAAPI同时争transform。

快速开关从当前状态合理中断，
不强制从初始scale重播造成跳动。

退出生命周期与animation/cancel一致。
不能CSS220ms、JS180ms提前卸载。

真实撤权和换号立即清除失效内容，
不为了退出动画保留敏感数据。

正常关闭、查询skip、暂时网络错误、
确认权限失效不是同一状态。

先保证反馈准确，
不通过动画掩盖错误位置、刷新乱序或丢草稿。
