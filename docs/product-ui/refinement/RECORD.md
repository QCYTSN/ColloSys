## 具体改变

- **构图**：全局工具留在安静的顶栏；团队切换与全局项目、任务、会话入口归入左栏；项目身份、属性菜单和工作页签集中在工作区内。原标签恢复、侧栏折叠、可调整宽度及原生会话栏继续使用。`ProductProjects` 读取原项目 store 和授权查询，改为项目索引与选中项目概览，替换正式 `/projects` 的 CompanyDocument 展示。成员、最近活动、连接目录和待处理交接均有真实来源，没有新建指标模型。
- **设置与浮层**：原 1080px 左导航面板改为 920px 的账号/工作区分组导航；内容、遮罩、标题和滚动区分别有明确 class。普通 Radix 对话框、交接表单、菜单使用同一表面规则，保留原焦点和键盘机制。
- **控件与阅读**：删除覆盖字号/字重/行高的全局 `font` 简写及覆盖按压反馈的全局按钮 transition。真实小按钮由基线 **13px / 400 / 19.5px** 恢复为 **12px / 500 / 16px**，高度仍为 32px，保留 80ms transform。输入框、Select、图标按钮和菜单分别校准。功能图标按原 strokeWidth 映射少量 Phosphor weight；真实 AgentTypeIcon/BrandIcons 没有被通用终端图标替换。实际中文字体查询确认 Microsoft YaHei UI，Google Sans 与花生资产链保持原样。
- **内容与连续性**：活动优先显示真实变更标题/请求片段，会话列表使用已有捕获事件文本，不生成摘要。全局 Conversations 阅读保持 `/inbox` 来源。设置与详情保留可中断的退出阶段；权限失效直接清除。原 InboxStore 内保存有身份/项目范围的分页游标、消息锚点与相对位置、Diff 原路径/行号、未发送交接草稿及来源。返回时重新走原授权查询，不缓存授权或复制业务记录。交接打开指令在关闭时消耗，避免项目地址规范化导致切回页签重复弹出。
- **代码审查**：原 FileDiffLayout 填满剩余工作区域，代码区负责滚动；完整性始终可见，来源、截断与恢复限制仍可展开。保留解析器、虚拟化、原路径、行号及原恢复保护。

遮住品牌后，对比页仍能看到三处结构差异：工作区内的项目身份/页签、真实项目索引加概览、横向分组设置。任务、评论、Diff 和原生会话的成熟内部行为继续复用；这不是重新制作一套简化业务替身。画面是否达到预期由用户判断，本记录不以测试数量或自评分宣告视觉通过。

## 边界

UI hints 为当前登录会话内最多 80 项的临时展示状态，不承诺关闭应用或整页刷新后恢复未发送草稿。项目概览读取最近 4 条活动和最近 10 条交接，不声称统计了全部历史待办。原生 live session 与 connector 捕获会话仍是各自原有数据源，顶部原生搜索不扩充为捕获日志全文搜索。

本轮没有确认执行真实文件恢复、发送邀请、调用付费模型、公开部署或推送代码；历史中已有恢复事件来自此前验收。保留原恢复测试与实现，但没有重新运行含实际恢复写盘的整套桌面测试。没有证明 60fps、完整辅助技术兼容、多物理显示器、其他操作系统安装器或公网容量。所有当前服务监听 127.0.0.1。
