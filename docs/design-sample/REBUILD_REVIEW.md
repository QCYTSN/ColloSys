## 对照依据与复用边界

更多菜单中的“同内容原生会话对照”加载固定版本 Codecast 的实际 ConversationView，使用与新样板一致的测试消息，保持原组件样式。[原生阅读器截图](screenshots/rebuild/10-native-reference.png)用于比较会话内容组织。它只覆盖原生会话阅读器，不代表完整原生产品的账号、项目、桌面和生产会话流程。

新样板直接组合原生 ConversationHeaderBar 框架，复用 FilePatchDiff 和 shouldFollowStreaming 策略；其他样板信息组织与视觉由自有实现完成。来源和修改已记录在根目录 THIRD_PARTY_NOTICES.md。原始源码保持固定版本且没有编辑。新规则见 [当前设计记录](rebuild/DESIGN.md)，不推广为全站已批准规范。

## 独立复核

初次独立复核返回 `fix`，要求修复以下两项。修复后复核返回 `disposition: ship`，范围仅限此隔离样板可以交用户评价；它不是用户的视觉认可。

| 发现 | 结果 |
| --- | --- |
| 队友只读范围不应打断整个工作台 | 已修复：历史条目内展开，保留来源、文件路径和权限边界；本机恢复仍有确认弹窗 |
| 缺少帮助理解结构变化的实际动效 | 已修复：实际逐帧测得高度从 0 连续增长到约 295 px，约 180 ms 完成；折叠内容使用 inert 与 aria-hidden |

复核在提供的截图和验证记录中没有发现这两项修复引起的实质回归。整理设计记录时另发现浮层根元素未完全遵循减少动效设置，随后补充了菜单、弹窗和遮罩的 CSS 覆盖与实际计算样式检查。

## 失败记录与边界

开发模式首次冷加载在图标依赖优化期间超时；变窄区域的首次阈值测试暴露了约 703 px 的实际可用宽度，随后调整为 760 px 折叠证据区。首次代码注释对比度为 4.459:1，已加深并重新验证。最后浮层动效修正的首次重构建被运行锁拒绝；确认并停止本轮自己的服务后才重新构建。这些失败不计为通过。

本轮没有接入样板到真实会话、任务/评论/交接或备份管理，也没有完成所有页面迁移、暗色版本、大列表性能、完整无障碍、安装更新或公网验证。原有后端与本地连接程序保持原实现，并执行了真实集成回归。当前样板不声称已经达到或超过 Codecast 的整体完成度。
